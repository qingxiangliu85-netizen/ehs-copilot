# EHS Copilot v0.1 测试结果

## 测试范围

- 执行日期：2026-08-28
- 场景问题：26 个
- 测试文档：3 份程序生成的模拟 SDS，共 21 个文本页
- 化学品：HF、HCl、Acetone
- 文档性质：仅用于软件测试的虚构文档，不是供应商 SDS，不得用于实际 EHS 决策
- 覆盖内容：危险性、PPE、储存、皮肤/眼睛接触急救、吸入急救、泄漏处置、消防措施、多文档、中英文提问、缺失信息拒答

## 自动化检查项

每个场景检查：

1. 检索上下文包含预期证据标记；
2. 来源文件与问题指定的化学品一致；
3. 来源页码包含预期页；
4. 单化学品查询不混入其他 SDS；
5. 多文档查询只包含问题明确指定的 SDS；
6. 传给 LLM 的上下文不包含无关化学品；
7. 不存在的信息直接返回“当前 SDS 知识库中未找到相关信息。”；
8. 拒答场景不调用 LLM。

## 本轮修复

- 修复向量检索固定返回 top-k，导致无答案问题仍进入 LLM 的问题；
- 修复多 PDF 下相似安全措辞导致其他化学品来源混入的问题；
- 基于文件名和 SDS 第一页产品名称生成通用产品别名，用于问题指向识别；
- 基于 SDS 标准章节号进行主题过滤，缺少对应章节时直接拒答；
- 对跨页章节沿用上一页章节元数据，减少章节正文没有重复标题时的漏检。

## 边界

- 当前环境未配置 `OPENAI_API_KEY`，所以没有对真实在线模型输出做端到端事实性判定；已验证模型输入上下文、拒答前置逻辑和引用链路。
- 模拟 SDS 只验证软件行为，不代表真实化学品安全建议。
- 扫描 PDF 仍不支持 OCR。
- 非标准章节标题、没有可提取产品名称且文件名含义模糊的 SDS，文档隔离能力可能下降。
