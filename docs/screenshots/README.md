# GitHub 展示截图清单

当前已包含 `initial-ui.png`，用于展示应用初始界面。发布前建议再使用公开、可再分发或自行制作的模拟 SDS 截取以下画面：

1. `01-initial-ui.png`：尚未上传文件的初始界面；
2. `02-multi-pdf-indexed.png`：上传至少两份 SDS 并成功构建知识库，侧栏显示文件数、文本页和文本块；
3. `03-grounded-answer.png`：正常问题、简洁回答、来源文件和页码同时可见；
4. `04-not-found.png`：询问 SDS 未记载的信息，显示标准拒答提示；
5. `05-bilingual-query.png`：英文问题与英文回答，证明双语查询链路可用。

截图前必须确认：

- 不显示 API Key、终端环境变量或账号信息；
- 不显示本地绝对路径、个人姓名、实验室成员或企业内部资料；
- 不使用版权和公开许可状态不明确的真实 SDS；
- 浏览器画面只保留应用区域，裁掉无关标签页和桌面信息；
- README 中优先展示第 2、3、4 张，初始界面可作为补充。
